# Шрифты (локально)

Файлы `.woff2` копируются скриптом `npm run fonts:copy` из `@fontsource` (только сборка, не CDN).

Отдаются как `https://pushes.su/fonts/...` — **без Google Fonts**.

Не удаляй вручную после `fonts:copy` — только эти 5 файлов:

- `Montserrat-400.woff2` … `700.woff2`
- `LobsterTwo-400.woff2`
